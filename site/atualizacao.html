    Atualização semanal

    O agendador do sistema roda todo dia atualizar --se-vencido --quiet; o programa só atualiza quando o intervalo (7 dias por padrão) venceu. Computador desligado na hora? Atualiza na vez seguinte.

    Criar o agendamento

    baseconhecimento agendar                      # imprime o comando para o seu sistema
baseconhecimento agendar --sistema cron       # windows, cron ou systemd

    Exemplo no Windows (Agendador de Tarefas):

    schtasks /Create /SC DAILY /ST 12:00 /TN "baseconhecimento-default" /TR "\"C:\caminho\baseconhecimento.exe\" --profile default atualizar --se-vencido --quiet"

    No app Android

    O app cuida do agendamento sozinho: em Configurações ligue Atualizar sozinho e escolha o intervalo. O Android confere uma vez por dia e o app só baixa quando o intervalo vence (padrão 7 dias).

    Ajustar

    baseconhecimento config --auto-atualizar false   # pausa
baseconhecimento config --intervalo-dias 3
baseconhecimento status                          # última atualização e se venceu

    É preciso ter uma sessão válida (baseconhecimento login). Se ela expirar, a execução agendada falha pedindo novo login; a senha nunca fica guardada no agendador.

    Mais detalhes (cron e systemd) em docs/agendamento.md.
