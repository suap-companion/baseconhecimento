    Usar

    Cada comando tem ajuda: baseconhecimento <comando> --help.

    Baixar e atualizar

    baseconhecimento atualizar                  # incremental: só baixa o que mudou
baseconhecimento atualizar --forcar         # baixa tudo de novo
baseconhecimento atualizar --id 123         # só esta entrada (mesmo fora das áreas listadas)
baseconhecimento atualizar --sem-anexos
baseconhecimento atualizar --podar          # apaga o que sumiu do SUAP

    No fim, o resumo conta entradas novas, atualizadas, sem mudança, sem acesso (o SUAP não deixa a sua conta ver) e falhas. O progresso mostra só ids.

    Listar e ler

    baseconhecimento listar
baseconhecimento listar --area tecnologia --visibilidade privada
baseconhecimento mostrar 123                # o Markdown da entrada, com os metadados no topo

    As entradas também são arquivos comuns em baseconhecimento paths → cópia local → entradas/: abra no seu editor, no Obsidian ou em qualquer ferramenta de Markdown.

    Buscar

    baseconhecimento buscar impressora toner
baseconhecimento buscar --limite 10 --json acesso vpn

    A busca é por palavras, ignora acentos e maiúsculas e vale para o texto das entradas e para anexos TXT, Markdown e PDF (com texto). Mostra a entrada, a visibilidade e de onde veio o trecho.

    Status e configurações

    baseconhecimento status
baseconhecimento config --intervalo-dias 7 --auto-atualizar true --anexos true
baseconhecimento reindexar                  # refaz o índice a partir dos arquivos

    Perfis

    baseconhecimento profile list
baseconhecimento --profile homologacao profile init --base-url https://suap-homolog.exemplo.br/
baseconhecimento --profile homologacao atualizar

    Cada perfil tem sessão, cópia local e configurações próprias.
