    Instalar

    Um único programa de linha de comando, sem instalador. Versão mais recente: ….

    Baixar

    • Windows (x86_64, .zip)
    • Linux (x86_64, .tar.gz)
    • Linux (arm64, .tar.gz)
    • macOS (Apple Silicon, .tar.gz)

    Extraia o arquivo e coloque o programa numa pasta do seu PATH. A release traz também o SHA256SUMS.txt para conferir o download.

    Primeiro uso

    baseconhecimento profile init --base-url https://suap.ifrn.edu.br/ --username seu_usuario
# PowerShell: $env:SUAP_PASSWORD = 'sua_senha'   |   Linux/macOS: export SUAP_PASSWORD='sua_senha'
baseconhecimento login
baseconhecimento atualizar

    A senha só é lida da variável SUAP_PASSWORD, na hora do login, e não é salva. Se você já usa o chamados, o perfil já existe: os dois programas compartilham o ~/.config/suap/config.toml (a sessão e a cópia local são separadas).

    O baseconhecimento não é um projeto oficial do IFRN nem do SUAP. · suap-companion
